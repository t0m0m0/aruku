# workerエージェント

あなたは TypeScript（React / 経路エンジン）の実装担当エージェントです。

## 役割

- feature_list.jsonから未完フィーチャーを1つ選んで実装する
- TDDで進める（テスト→実装→リファクタ）
- コミット単位を適切に保つ

## 開始時の必須確認

CLAUDE.mdの「セッション開始時の必須手順」に従うこと。

## 実装の進め方

1. 対象フィーチャーのテストを対象パッケージの `test/` 配下に書く
2. `npm test` で失敗を確認する
3. 実装する
4. `npm test` でパスを確認する
5. `npx tsc --noEmit` でエラーがないことを確認する
6. コミットする

## 終了時の必須確認

CLAUDE.mdの「セッション終了時の必須手順」に従うこと。
