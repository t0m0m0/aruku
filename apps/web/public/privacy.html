プライバシーポリシー

【運営者名】（以下「運営者」）は、経路検索サービス「aruku」（https://aruku.pages.dev、以下「本サービス」）における利用者の情報の取扱いについて、以下のとおり定めます。

1. 基本方針

本サービスは、アカウント登録なしで使えます。氏名・メールアドレス・電話番号など、利用者を直接特定する情報は求めません。経路を検索するために必要な情報だけを扱い、運営者のデータベースに保存することはありません。

2. 取得する情報と利用目的

情報取得の方法利用目的
現在地（緯度・経度） ホーム画面・検索画面を開いたとき、および現在地を更新する操作をしたとき（ブラウザで位置情報の利用を許可している場合のみ。初回はブラウザが許可を求めます） 出発地の設定、経路の計算、地点検索で現在地に近い候補を優先して並べること
検索語・出発地・目的地・日時 利用者の入力 地点の検索、経路の計算
IP アドレス 通信に伴って自動的に 不正利用・過剰なアクセスの防止（レート制限）
ブラウザ・端末に関する情報 不正利用防止の仕組み（reCAPTCHA）が自動的に 本サービスへの正規のアクセスかどうかの判定

上記以外の目的には使いません。

保存について

  • 現在地・検索語・経路は、検索を処理するために送信するだけです。運営者のデータベースには保存しません。
  • ただし、同じ徒歩経路への重複した問い合わせをまとめるため、徒歩経路の計算結果（地点の座標を含む）を運営者のサーバのメモリ上に短時間（目安30秒）保持します。ディスクやデータベースには書き込まず、件数の上限を超えたとき、またはサーバの処理単位（インスタンス）が終了したときに破棄されます。
  • IP アドレスは、そのまま保存しません。日ごとに変わる鍵で不可逆に変換した値を、アクセス回数を数えるために短時間だけ保存し、自動で削除します。
  • ただし、運営者が利用するクラウド基盤（Google Cloud）は、通信の記録（IP アドレス、ブラウザの種類、アクセス日時など）をシステムログとして一定期間【保持期間を確認：既定30日】保持します。運営者は、障害対応と不正利用への対処のためだけにこれを参照します。
  • 最近使った地点は、利用者のブラウザ内（localStorage）にだけ保存します。運営者には送信されません。ブラウザのサイトデータを削除すれば消えます。

3. 外部サービスへの送信

本サービスは、機能を提供するために、次の外部サービスへ情報を送信します。

送信先送信する情報目的送信先のプライバシーポリシー
Cloudflare, Inc.（Cloudflare Pages） IP アドレス、ブラウザの情報、アクセス日時、閲覧したページの URL 本サービスのページの配信、配信基盤の安全確保 Cloudflare プライバシーポリシー
Google LLC（Google Maps Platform：Maps JavaScript API、Places API、Routes API） 地図の表示範囲、検索語、現在地および地点の座標、IP アドレス、ブラウザの情報 地図の表示、地点の検索（現在地に近い候補の優先を含む）、徒歩経路の計算 Google プライバシーポリシー
Google LLC（Firebase App Check、reCAPTCHA） ブラウザ・端末に関する情報、IP アドレス 不正利用の防止 Google プライバシーポリシー
Transit API（api.transit.ls8h.com）【運営者名を確認】 出発地・目的地の座標、日時、IP アドレス、ブラウザの情報（User-Agent・送信元のページなど、ブラウザが通信に付ける情報） 公共交通の経路の計算 【URL を確認】

地図の表示には Google マップを使っています。Google マップの利用には、Google マップ / Google Earth 追加利用規約とGoogle プライバシーポリシーが適用されます。

本サービスは、広告配信やアクセス解析を目的とするツール（Cookie による追跡を含む）を使っていません。

4. 第三者提供

運営者は、次の場合を除き、取得した情報を第三者に提供しません。

  • 前項の外部サービスへ、機能の提供に必要な範囲で送信する場合
  • 法令に基づく場合
  • 人の生命・身体・財産の保護のために必要で、本人の同意を得ることが難しい場合

5. 安全管理

通信はすべて暗号化（HTTPS）しています。地点検索と徒歩経路の計算に使う API キーは運営者のサーバ側で管理し、利用者のブラウザには渡しません。なお、地図の表示（Google Maps JavaScript API）と Firebase の利用には、ブラウザから使う前提の公開用キーが必要なため、これらは本サービスのページとともにブラウザへ配信されます。いずれも利用者を識別する情報ではありません。

6. 位置情報の利用をやめるには

現在地の利用は、ブラウザの設定からいつでも取り消せます。取り消した後も、地点を検索して出発地を指定すれば本サービスを使えます。

7. 開示等の請求

前述のとおり、運営者は利用者を特定できる情報を保存していません。そのため、多くの場合は開示・訂正・削除の対象となる情報がありません。ご不明な点は、第9項の窓口へお問い合わせください。

8. 改定

本ポリシーは、必要に応じて改定することがあります。重要な変更がある場合は、本サービス上でお知らせします。改定後のポリシーは、本ページに掲載した時点から効力を生じます。
