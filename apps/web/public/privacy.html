プライバシーポリシー

経路検索サービス「aruku」（以下「本サービス」）は、アカウント登録なしで使えます。氏名やメールアドレスなど、利用者を直接特定する情報は求めません。本ポリシーでは、本サービスが扱う情報とその使い道を説明します。

1. 取得する情報と利用目的

情報取得するとき利用目的
現在地（緯度・経度） ホーム画面・検索画面を開いたとき、現在地を更新したとき（ブラウザで位置情報を許可している場合のみ） 出発地の設定、経路の計算、地点検索で近い候補を優先すること
検索語・出発地・目的地・日時 入力したとき 地点の検索、経路の計算
IP アドレス・ブラウザの情報 通信のたびに自動で ページの配信、不正利用や過剰なアクセスの防止

2. 外部サービスへの送信

本サービスは、次の外部サービスへ情報を送信します。

送信先送信する情報目的
Cloudflare Pages（Cloudflare, Inc.） IP アドレス、ブラウザの情報、閲覧したページ ページの配信
Google Maps Platform（Google LLC） 検索語、現在地と地点の座標、地図の表示範囲、IP アドレス、ブラウザの情報 地図の表示、地点の検索、徒歩経路の計算
Firebase App Check・reCAPTCHA（Google LLC） IP アドレス、ブラウザ・端末の情報 不正利用の防止
Transit API（個人が運営する非公式の公共交通経路 API） 出発地・目的地の座標、日時、IP アドレス、ブラウザの情報 公共交通の経路の計算

Google マップの利用には、Google マップ / Google Earth 追加利用規約とGoogle プライバシーポリシーが適用されます。本サービスは、広告やアクセス解析のためのツールを使っていません。

3. 保存について

  • 現在地・検索語・経路を、データベースに保存することはありません。
  • ただし、地点検索と徒歩経路の計算では、検索語と座標（現在地を含む）が通信の記録の一部として Google Cloud のシステムログに残り、30日後に削除されます。また、徒歩経路の計算結果は、重複した問い合わせをまとめるため、サーバのメモリ上に短時間（目安30秒）保持します。
  • 最近使った地点は、ブラウザ内にだけ保存します。ブラウザのサイトデータを削除すると消えます。

4. 位置情報の利用をやめるには

ブラウザの設定から、いつでも位置情報の許可を取り消せます。取り消した後も、地点を検索して出発地を指定すれば本サービスを使えます。
